# Clean workspaces · демо workflow

Демо для Finam X на прод-доске 8968 «Начни утро с обзора рынка»: создатель собирает доску в workflow и настраивает его, пользователь подключает готовое пространство и видит собранный workflow с отчётами.

Открыть: `index.html` в браузере — один файл, без сборки и зависимостей.

## Версия
Демо 1.7 · 17.10.2026. Основа — слайдовер до визарда, итерация 10.57 основной линии прототипа.

## Сценарии
- **Создатель.** «Сгруппировать в workflow» — доска собирается в workflow. Клик по карточке открывает слайдовер с настройками рутин; там же — визард «Вид карточки». Отчёты лежат рядом на доске или внутри workflow. «Разгруппировать» возвращает граф на доску.
- **Пользователь.** «Готовые пространства» → «Начни утро с обзора рынка» → «Подключить пространство»: открывается доска с собранным workflow и отчётами. Если создатель в этом демо уже собрал и настроил workflow — пользователь получает именно его.
